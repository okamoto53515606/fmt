JSON 整形・構文チェック

JSONを貼ると整形し、構文エラーがあれば「何行目の何文字目か」「よくある原因」を日本語で示します。エラーメッセージが英語で分かりにくいときにも使えます。

このページの解説とよくある質問を読む

入力

入力した内容は送信されません。 解析はこのブラウザの中だけで完結します（サーバーがありません）。

画像はここにドラッグ＆ドロップ

スクリーンショットは Ctrl+V で貼り付けできます。入力は保存しません（再読み込みで消えます）。

JSONでよくあるエラーと直し方

症状原因直し方
Unexpected token }末尾のカンマ（ケツカンマ）[1,2,] → [1,2]
Unexpected token 'シングルクォート'a' → "a"
Unexpected token あキーや値の引用符がない／全角の「”」半角の " に直す
Unexpected end of JSON input括弧の閉じ忘れ、途中で切れている{ と [ の数を数える
Unexpected token NNaN / Infinity / コメントJSONに存在しない値。文字列か null にする

このツールは、エラー位置を行・文字位置で示し、上の表のような「よくある原因」を日本語で添えます。

JSONとJavaScriptオブジェクトの違い

JavaScriptのオブジェクトリテラルはJSONより緩く、シングルクォート・末尾カンマ・コメント・関数・ undefined が書けます。JSONはこれらをすべて許しません。 「ブラウザのコンソールでは動くのに、JSONとして読むと失敗する」ときは、この差が原因です。

JSON Lines（1行1JSON）との違い

JSON Lines（NDJSON）は「1行に1つのJSON」を並べた形式で、ログやストリームで使われます。 配列ではないので、そのままではJSONとして読めません。このツールは {…}\n{…} の形を見つけるとJSON Linesとして判定し、表に整形します（CSVとは誤認しません）。

大きいJSONの扱い

テキストは4MBまで解析します。超えた場合は先頭4MBだけを対象にし、その旨を結果に明記します。 数万行のログを貼る場合は、行を絞るかJSON Linesのまま貼るほうが扱いやすくなります。

このツールの安全性

解析はすべてブラウザの中で行います。サーバーが無いので、入力した内容が送られる先がありません。 配信側の CSP（Content-Security-Policy）で fetch / XMLHttpRequest / WebSocket / sendBeacon を禁止しており（connect-src 'none'）、ビルド時に scripts/check-no-network.mjs が送信 API の混入を検査しています。 入力は保存しません（再読み込みで消えます）。一度読み込めばオフラインでも動きます。

このページの判定は決まったルールによるもので、AI（LLM）は使っていません。同じ入力なら同じ結果になります。 マスキングには取りこぼしがあります。共有前の目視確認をおすすめします。

よくある質問

エラーの場所を教えてくれますか？

はい。何行目の何文字目かを示し、よくある原因（末尾カンマ、シングルクォート、全角引用符など）を日本語で添えます。

JSONをそのままAPIに送れますか？

このツールは整形と表示までです。整形結果はコピーできますが、送信は行いません（CSPで外部通信を禁止しています）。

キーを並べ替えたり、値を変換したりできますか？

いいえ。整形と構文チェックが目的です。並べ替えやマッピングは行いません。

個人情報を含むJSONでも安全ですか？

入力は送信されず、保存もされません。ただし既定でONのマスキングはメールアドレスなどを伏せて表示するため、値そのものを見たいときはチェックを外してください。

JSON LinesはCSVとして表示されますか？

いいえ。1行1JSONの形を検出してJSON Linesとして扱います。表に整形し、入れ子は「親.子」の列名にします。

fmt は「貼るだけで何なのかが分かる」ブラウザ完結のツールです。サーバーを持たず、入力した内容を送信しません。 結果は決まったルールで判定しており、AI（LLM）は使っていません。

使い方と安全性

これは何？

意味がわからない文字列やファイルを貼ると、何なのか・どこが問題なのかを日本語で説明する道具です。 解析はすべてブラウザの中だけで行い、入力した内容をどこにも送信しません（サーバーがありません）。

できること

  • JWT・JSON・XML・HTML・CSV / TSV・ログ・メールのソース・Cookie・URL・証明書 / 鍵 の解析（日時は日本時間、列の多い表は縦横変換）
  • Base64・URL エンコード・16進ダンプ・Unicode エスケープの解除（解除した先も自動で判定します）
  • 画像（複数可）の形式・サイズ・EXIF・GPS・QR コード / バーコード
  • エラーの意味（HTTP / SMTP / よくある英語エラー）と、次にやること
  • 文字数・行数・バイト数・文字コード・改行・環境依存文字などの統計
  • 機密情報のマスク（メール・電話・APIキー・カード番号・AWS アカウントID・2段階認証のシークレットなど）

安全のためにやっていること

  • 配信元の CSP（Content-Security-Policy）で、fetch / XHR / WebSocket / beacon などの送信路を禁止しています（connect-src 'none'）。ブラウザのページ遷移そのものは CSP では止められません。
  • 解析は Web Worker で行い、画面が固まりにくいようにしています。
  • 一度読み込むと、オフラインでも動きます（Service Worker）。
  • 入力は保存しません。再読み込みすると消えます。
  • AI（LLM）は使っていません。すべて決まったルールで判定します（結果が毎回同じになります）。
  • HTML は「ソース」として表示し、ページとしては表示しません。Markdown 内のスクリプト・外部画像も無効化します。

できないこと（正直な制限）

  • 暗号化されたデータの中身は読めません（種類の推定まで）。
  • ハッシュ値は「元に戻す」ことはできません。長さからの推定のみです。
  • 英語の長文を自然に翻訳することはしません。よくあるエラーの意味を辞書で引く方式です。
  • JWT の署名検証、証明書の失効確認は行いません。
  • マスキングは取りこぼしがあります。共有前の目視確認をおすすめします。

注意

この画面は通信しませんが、貼り付けた先のサービス（チャット・メール・チケット）には内容が残ります。 秘密鍵やパスワードは、そもそも他人に送らないでください。

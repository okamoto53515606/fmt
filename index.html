使い方と安全性

これは何？

意味がわからない文字列やファイルを貼ると、何なのか・どこが問題なのかを日本語で説明する道具です。 解析はすべてブラウザの中だけで行い、入力した内容をどこにも送信しません（サーバーがありません）。

できること

  • JWT・JSON・XML・HTML・CSV / TSV・ログ・メールのソース・Cookie・URL・証明書 / 鍵 の解析（日時は日本時間、列の多い表は縦横変換）
  • Base64・URL エンコード・16進ダンプ・Unicode エスケープの解除（解除した先も自動で判定します）
  • 画像（複数可）の形式・サイズ・EXIF・GPS・QR コード / バーコード
  • エラーの意味（HTTP / SMTP / よくある英語エラー）と、次にやること
  • 文字数・行数・バイト数・文字コード・改行・環境依存文字などの統計
  • 機密情報のマスク（メール・電話・APIキー・カード番号・AWS アカウントID・2段階認証のシークレットなど）

安全のためにやっていること

  • 配信元の CSP（Content-Security-Policy）で、外部への通信をすべて禁止しています（connect-src 'none'）。
  • 解析は Web Worker で行い、画面が固まりにくいようにしています。
  • 一度読み込むと、オフラインでも動きます（Service Worker）。
  • 入力は保存しません。再読み込みすると消えます。
  • AI（LLM）は使っていません。すべて決まったルールで判定します（結果が毎回同じになります）。
  • HTML は「ソース」として表示し、ページとしては表示しません。Markdown 内のスクリプト・外部画像も無効化します。

できないこと（正直な制限）

  • 暗号化されたデータの中身は読めません（種類の推定まで）。
  • ハッシュ値は「元に戻す」ことはできません。長さからの推定のみです。
  • 英語の長文を自然に翻訳することはしません。よくあるエラーの意味を辞書で引く方式です。
  • JWT の署名検証、証明書の失効確認は行いません。
  • マスキングは取りこぼしがあります。共有前の目視確認をおすすめします。

注意

この画面は通信しませんが、貼り付けた先のサービス（チャット・メール・チケット）には内容が残ります。 秘密鍵やパスワードは、そもそも他人に送らないでください。

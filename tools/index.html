ツール一覧

fmt は「意味がわからない文字列やファイルを貼ると、何なのかを日本語で説明する」ツールです。目的別にページを分けています。どのページでも、解析はブラウザの中だけで行います。

目的から探す

  • URLエンコード・デコード 日本語やスペースをURLで使える形式（パーセントエンコーディング）に変換・復元。%E3%81%82 のような文字列を読める文字に戻します。二重エンコードも解除。入力はブラウザの外に出ません。
  • Base64エンコード・デコード テキストをBase64に、Base64をテキストに変換。日本語（UTF-8）対応、URL-safe形式も判定。data URIを貼れば画像として表示・保存できます。入力はブラウザの外に出ません。
  • JWT デコード JWT（JSON Web Token）を貼ると、ヘッダ・Payload・有効期限（exp / iat / nbf）を日本時間で表示します。期限切れは警告。署名の検証は行いません。トークンは送信しません。
  • JSON 整形・構文チェック JSONを貼ると整形し、構文エラーがあれば何行目の何文字目かとよくある原因を日本語で示します。JSON Lines（1行1JSON）も自動判定。入力はブラウザの外に出ません。
  • 写真のEXIF・GPS位置情報を確認 写真をドロップすると、撮影日時・カメラ・GPS座標などのEXIF情報を表示し、位置情報が残っているかを判定します。画像はアップロードされません。

どのページでも同じように使えます

  1. 文字列を貼り付ける（画像はドラッグ＆ドロップ）
  2. 結果・統計・補足が自動で出ます
  3. 必要なら「機密情報をマスク」を確認してからコピー・保存します

解析はすべてブラウザの中で行います。サーバーが無いので、入力した内容が送られる先がありません。 配信側の CSP（Content-Security-Policy）で fetch / XMLHttpRequest / WebSocket / sendBeacon を禁止しており（connect-src 'none'）、ビルド時に scripts/check-no-network.mjs が送信 API の混入を検査しています。 入力は保存しません（再読み込みで消えます）。一度読み込めばオフラインでも動きます。

このページの判定は決まったルールによるもので、AI（LLM）は使っていません。同じ入力なら同じ結果になります。 マスキングには取りこぼしがあります。共有前の目視確認をおすすめします。
